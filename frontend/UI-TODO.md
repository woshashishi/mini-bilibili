# 前端接口联调状态

已有业务接口已接入：注册、登录、当前身份、Feed游标分页、视频详情、点赞、取消点赞、点赞状态、点赞数、文件上传、视频发布、静态播放；页脚可检查健康状态。

上传入口支持本地MP4和已有HTTP/HTTPS视频链接。文件上传成功后才允许发布，发布失败保留上传结果。发布成功刷新首页。
401清除对应会话；旧请求的401不会清除新账号的凭证。退出仅清除前端状态，不能撤销已经签发的JWT。

仍为布局演示：顶部精选、排行榜。尚无后端接口：分区、全站搜索、收藏、历史、消息、评论。没有伪造这些功能的成功状态。
搜索仅作用于已加载视频。后端暂无封面、用户名详情、转码和文件删除接口。

开发：后端8000，Vite开发代理转发 /api、/uploads、/healthz。生产部署需配置反向代理。
说明见 API-GUIDE.md。测试：node --test src/composables/useAuth.test.js src/api/business.test.js；构建：npm run build。
